# Expense Reporting & KPI Dashboard (Power BI)

## Overview
This project is an end-to-end **expense reporting and financial analysis dashboard** built using **Power BI**, **Excel**, and **DAX**.  
It analyzes transactional data to provide insights into **expenses, income, net cash flow, category breakdowns, and monthly trends**.

## Tools & Technologies
- Power BI (DAX, Data Modeling)
- Microsoft Excel
- Star Schema (Fact + Date Dimension)
- Data Visualization & KPI Reporting

## Key Features
- Total Expenses, Total Income, Net Cash Flow KPIs
- Expenses by Category (Bar & Donut Charts)
- Monthly Expense Trend Analysis
- Transaction-level drill-down table
- Interactive slicers (Month, Category, Merchant)
- Conditional formatting for expenses
